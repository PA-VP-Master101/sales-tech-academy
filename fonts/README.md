# Polices

Les trois familles de caractères du site sont hébergées ici, pour éviter tout appel à Google Fonts au chargement des pages.

| Police | Usage | Licence |
|---|---|---|
| [Bricolage Grotesque](https://github.com/ateliertriay/bricolage) | Titres | SIL Open Font License 1.1 |
| [Inter](https://github.com/rsms/inter) | Texte | SIL Open Font License 1.1 |
| [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | Chiffres et code | SIL Open Font License 1.1 |

Seuls les sous-ensembles `latin` et `latin-ext` sont inclus, au format WOFF2 variable.
Texte de la licence : <https://openfontlicense.org/open-font-license-official-text/>
